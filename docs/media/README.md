# Media

Drop gameplay captures here so the root `README.md` renders them. The README
references these exact filenames:

| File | What it is | Suggested size |
|---|---|---|
| `cover.png` | Hero shot used as the GitHub social-preview / Open Graph image | 1280×640 |
| `gameplay.gif` | Short looping clip of a Chaotic Era → dehydration → rebirth | ≤ 10 MB, ~10–15 s |
| `orbit-map.png` | The Orbit Map / Computer ensemble-forecast view | 1280×720 |
| `eras.png` | HUD during a Stable Era with the climate chart | 1280×720 |

Tips for good captures:
- Run the game full-screen, hide the cursor, and let a dramatic moment unfold
  (a syzygy, a flying-star deep freeze, or the fleet launch).
- For the GIF, [ScreenToGif](https://www.screentogif.com/) (Windows) or
  the macOS screen recorder → convert to GIF keeps file size reasonable.
- Keep `cover.png` readable as a thumbnail — large title, one striking visual.
